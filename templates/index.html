Bill of Entry (BOE) Statutory Formula:
• BCD = Assessable Value × BCD Rate
• SWS = 10% × BCD Amount
• Import IGST (18%) = (Assessable Value + BCD + SWS) × 18%
• CGST (9%) = Import IGST × 9%
• SGST (9%) = Import IGST × 9%
• Total GST on IGST = CGST + SGST (Added directly to Total Landed Cost)
